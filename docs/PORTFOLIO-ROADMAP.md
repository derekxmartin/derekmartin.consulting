# Portfolio roadmap

The website supports published cases, demonstrations and technical walkthroughs. The portfolio currently has no supplied publishable material. The development fixture exercises the layout and makes no claims of completed client work.

1. **Floodlight / ad-network implementation.** Prioritize this example to reflect the principal service. Supply sanitized activity definitions, parameter mappings, tag/request evidence and actual destination checks. State explicitly when any part is simulated.
2. **Tracking repair walkthrough.** Show a reproducible failure, its root cause, the agreed correction and before/after retesting.
3. **Lead-generation demonstration.** A separate demo application with success/failure behavior, a defined event map and destination evidence for any live integration claims.
4. **Ecommerce demonstration.** A separate storefront/test flow with product, cart, checkout and purchase data, transaction/value checks and duplicate handling. Use synthetic customer data and test payments.

For every example, record the requirement, scope, implementation, verification, limitations and available evidence. Do not imply platform acceptance from a local event console. Use a real verification date only after running the checks.

Demo URLs remain configurable so follow-on applications can live on a separate domain, subdomain or Vercel URL. No additional demo applications were built as part of this website milestone.
