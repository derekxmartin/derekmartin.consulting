# Derek Martin website: Codex handoff

This bundle contains the website build specification and the original selected **Connected** aesthetic image. It is a design and implementation brief, not a built website.

## Included files

- [derek-martin-website-spec.md](derek-martin-website-spec.md): version 1.1, covering the business, pages, services, design, behavior, implementation and acceptance criteria.
- [references/connected-selected-reference.png](references/connected-selected-reference.png): the unchanged 1448 x 1086 selected concept, originally titled “Connected tracking, handled.png.”

## Use with Codex

1. Extract the complete ZIP into the project workspace. Keep the `references` folder beside the specification so its embedded image resolves.
2. Give Codex access to both files. In a chat interface, attaching the PNG directly alongside the specification can also make the visual reference easier to inspect.
3. Use the kickoff prompt in section 17 of the specification. Tell Codex to open the PNG before writing layout code and to follow section 4 in full.
4. Review the working site and its desktop/mobile screenshots against the image using the acceptance criteria in section 4.16.

The image supplies the visual character. The written specification supplies the actual navigation, service coverage, responsive behavior and functionality. The image's sample copy, platform marks and demonstration previews are not evidence of completed work or instructions to invent it.

The visual specification now defines the grid, Manrope type scale, colors, spacing, hero illustration, service rows, work previews, inner-page compositions, form states, navigation, motion and screenshot review. Working copy remains editable for the next round.
